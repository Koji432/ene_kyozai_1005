# 火力発電 3D

**[教材を開く](https://koji432.github.io/ene_kyozai_1005/)**

3Dモデルと操作ボタンだけの、ブラウザーで動く火力発電のアニメーションです。

## 操作

- **スタート**：復水器の水 → 給水ポンプ → ボイラーの加熱 → 高速の蒸気 → タービンと発電機 → 3本の電線・小型の変圧設備 → 街灯の点灯 → 電気自動車の充電と点灯、という流れを約38秒で追います。カメラも自動で移動し、街灯を点灯させた後、充電器と電気自動車へカメラが移動します。最後は車への電気の到達、充電口・ヘッドライトの点灯、床下の電池モジュールが順番に明るくなる場面を保持します。その後も運転のアニメーションは続きます。
- **最初から**：一連の流れを再生し直します。
- **一時停止／再開**、**0.5・1・2倍速**、下部のバーによる途中位置の指定。
- **追従ボタン**：カメラの自動追従を切り替えます。ドラッグすると追従は解除され、自由に見られます。
- **リセットボタン**：最初の停止状態へ戻ります。
- **外観・内部**：設備の外装を切り替えます。
- ドラッグ／1本指で回転、ホイール／ピンチで拡大縮小、右ドラッグで平行移動。設備をクリックすると拡大します。
- キーボードでは3D画面にフォーカスし、矢印キーで回転、＋／−で拡大縮小。

## モデルとアニメーション

提供写真の形状を参考にした学習用モデルで、実機のCADやスキャンデータではありません。ボイラーを使う汽力発電を、現象の順序がわかるよう時間を圧縮して表現しています。実際の発電所の起動手順・起動時間や、厳密な熱流体計算を再現したものではありません。

- 主系統の水・蒸気と冷却水は別の経路です。
- 炎はボイラー内にのみあります。燃焼ガスは蒸気系統とは別です。
- ドラムを持つボイラーとして、降水管・水冷壁管・蒸気ドラムを表しています。水管の中を透かし、青から暖色への変化、上昇して大きくなる気泡、ドラム内の液面と蒸気空間で加熱・沸騰を示します。色と粒、熱移動の矢印は観察のための強調表現です。
- タービンと発電機は同じ軸で、同じ角度・同じ速度で回ります。固定羽根とコイルは回りません。
- 回転速度や蒸気の速度は観察用です。蒸気の目印は給水の約6倍の移動速度で進みます。色や粒は流れを示すための表現で、実際の水蒸気は無色透明です。
- 黄色い流れは電気エネルギーの伝わる向きです。電子が一方向に移動することを示していません。発電機の磁極と固定コイルによる交流発電を簡略化しています。
- 発電機から3本の独立した導体で、小型の変圧設備1台に接続します。長距離の送電設備は省略し、開閉・保護機器は箱の内部にまとめた表現です。変圧器の巻線は省略し、内部の磁気的な結合を介してエネルギーが伝わる構成です。異なる相の端子を短絡させていません。
- 変圧設備から街灯に相線と中性線の2本を接続した閉回路を示します。内部表示では支柱を透かして配線を見せます。LEDの駆動回路は灯具内のものとして省略しています。灯具の発光と道路を照らす光で、電気が身近な場所で使われる様子を示します。電線上の粒が進む速度は実際の電気の伝達速度ではなく、設備間の関係を追うための演出です。発電所から需要家までの距離、設備の電気的離隔、配電分岐は圧縮・省略しています。
- 電気自動車は駐車したまま充電し、街灯と同じ小型変圧設備から給電します。充電ケーブルは往復の導体等を含む束を1本で表し、充電器・車載充電回路・電池制御の内部回路は省略しています。電池の色・発光はエネルギーが蓄えられることを強調する演出で、実際の充電時間・充電率ではありません。ヘッドライトは電気の利用を示すため点灯させます。
- 灯りの点灯は発電した電気を使う表現です。実際の励磁、系統同期、電圧・負荷制御、再熱・給水加熱、排ガス処理等は省略しています。

## 配信

GitHub Pagesの `main / (root)` からそのまま公開します。追加サーバー、APIキー、外部CDNは不要です。必要なライブラリはすべて同梱してあり、`index.html` を直接開いてオフラインでも利用できます。

編集用ソースは `app.js` と `style.css`、実行用は `app.bundle.js` です。ソース変更後の再ビルド：

```sh
npx --yes esbuild@0.25.11 app.js --bundle --minify --format=iife --outfile=app.bundle.js
```

Three.js 0.180.0のMITライセンスは `vendor/THREE-LICENSE.txt` にあります。

学習内容の参考：[電気事業連合会・火力発電](https://www.fepc.or.jp/supply/hatsuden/fire/)、[発電のしくみ](https://www.fepc.or.jp/sp/pikaru/basic.html)。

今回の設備表現の参考：[東京電力パワーグリッド・流通設備の概要](https://www4.tepco.co.jp/pg/consignment/retailservice/pdf/04_ryuutsuusetsubi.pdf)、[三菱重工・ボイラー](https://power.mhi.com/jp/products/boilers)。
